# Building QFILdroid

## Prerequisites

- Flutter stable 3.22+ (includes Dart 3.4+)
- Android SDK with platform 34
- Android NDK r26+ (native engine)
- CMake 3.22.1+ (bundled with Android Studio SDK manager)
- A device or emulator is NOT required for tests, only for deployment

## Steps

```bash
# 1. Fetch Dart dependencies
flutter pub get

# 2. Static analysis
flutter analyze

# 3. Dart unit tests
flutter test

# 4. C++ engine host tests (optional, no Android toolchain needed)
cd android/app/src/main/cpp/tests
cmake -S . -B build && cmake --build build && ./build/engine_tests
cd -

# 5. Build the APK (compiles the C++ engine via NDK/CMake)
flutter build apk --release
```

The first Android build downloads Gradle 8.4 and configures the NDK build
defined in `android/app/build.gradle` (externalNativeBuild -> CMake).

## Deploying

```bash
flutter devices          # confirm the OTG host device is visible
flutter install          # or: adb install build/app/outputs/flutter-apk/app-release.apk
```

## Notes

- `android/local.properties` is generated by the Flutter tool; do not commit it.
- The USB device filter (`android/app/src/main/res/xml/usb_device_filter.xml`)
  currently matches Qualcomm EDL IDs (05C6:9008/900E/901D) so attaching an
  EDL device offers "open QFILdroid" at the OS level.
- Hardware validation checklist lives in docs/FEATURE_STATUS.md.
